# Contributing

Thanks for helping grow **Awesome AI Tools**! Every addition makes the list more useful for everyone.

## Adding a tool

1. Fork the repository and edit `README.md`.
2. Add **one tool per pull request** to the most fitting category.
3. Keep entries in **alphabetical order** within their category.
4. Use exactly this format:

   ```markdown
   - [Tool Name](https://example.com) - Short description of what the tool does.
   ```

   For open-source projects, add the 🔓 tag:

   ```markdown
   - [Tool Name](https://github.com/owner/repo) - 🔓 Short description of what the tool does.
   ```

5. Open a pull request using the template and tick the checklist.

## Writing a good description

- One or two sentences, starting with a capital letter and ending with a period.
- Don't start the description with the tool's name.
- Say what the tool **does**, not how amazing it is. Avoid marketing language ("revolutionary", "best-in-class").
- Mention pricing if it matters (for example "free plan available" or "paid").

## What we don't accept

- Tools built for malware, fraud, or other malicious use.
- Sites that distribute pirated or copyrighted content.
- Broken links, link shorteners, or affiliate/referral links.
- Duplicates of tools already on the list.
- Tools with no AI functionality.

## New categories

If a tool doesn't fit any existing category, propose a new one in your PR. Give it an emoji, add it to the **Contents** list (with the same emoji) and keep categories in alphabetical order.

## Fixing or removing entries

Found a broken link, an outdated description, or a tool that has shut down? Open a pull request with the fix, or [open an issue](https://github.com/sajadh76/awesome-AI-tools/issues/new/choose).

## Automated checks

Every pull request runs a link checker and `awesome-lint`. Please make sure they pass. A maintainer will review your PR as soon as possible.
